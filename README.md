    <h1 align="center">Fast Sneak</h1>
</p>

Recreates the classic 1.8-style sneak visual instead of the lower sneak animation in new versions.

<h1>Functionality</h1>

- Sneak height adjustment (Pre-1.9, Pre-1.14, Normal)
- Animation toggle (toggle for both the normal sneak and when sneaking under a ceiling)
- Third person toggle
- Does not affect hitbox range, purely a visual change
